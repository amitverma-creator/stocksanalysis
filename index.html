One-time setup (2 minutes)
  1. Open script.google.com and create a new project.
  2. Click Copy Apps Script below, select all the code in the editor, paste, and press Save.
  3. Click Deploy → New deployment → type Web app → Execute as Me, Who has access Anyone → Deploy. Approve the permissions (Advanced → Go to project if Google warns).
  4. Copy the Web app URL and paste it here.
